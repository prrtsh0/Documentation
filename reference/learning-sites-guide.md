# Learning Sites Guide (context)

The practice sites I use to build fluency, and the format for logging each. This is the
**context** for the Learning Sites section of the main README — the live per-site progress
logs live in that README's horizontal table.

Plus: **StatQuest** (concepts, 5 videos in one sitting) and **Brilliant** (math, light).

## Sites

### Deep-ML — `deep-ml.org`
Implement ML/math from scratch. Pick problems matching the week's paper; implement without
peeking, then compare. Log: date, problem, topic, notes.

### TorchLeet — `torch.com`
PyTorch fluency practice. Goal: write PyTorch without looking things up. Log: date,
problem, topic, notes.

### LeetML — `leetml`
ML coding problems covering anything missed that week. 25-min try, then read solution,
close it, re-solve later. Log: date, problem, topic, notes.

### StatQuest
Concepts, clear explanations. Watch 5 videos in one sitting; afterwards write 3 lines on
what you had wrong or half-right (that is the point). Log: date, videos, half-right notes.

### Brilliant
Math, light — derivatives, chain rule, linear algebra, probability. Supplements the math
layers in the learning dependency map. Log: date, topic, notes.

## Log format
For each site keep a small table:
`| Date | Problem/Topic | Notes |`. The Notes column is free text (usable for the same
word2vec/sentiment analysis as the daily logs).
